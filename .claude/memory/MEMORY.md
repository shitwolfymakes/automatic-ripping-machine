# Memory

- [Memory for this repo lives in source control](feedback_memory_in_source_control.md) — memory is committed under `.claude/memory/`; CLAUDE.md instructs Claude to read MEMORY.md at session start. Don't write to the per-user `~/.claude/projects/<slug>/memory/` path.
- [DB enums stored as VARCHAR](feedback_db_enums_as_varchar.md) — never use Postgres CREATE TYPE enums; validate enums in the app layer at write time.
- [Ripper: one makemkvcon per disc, never per title](feedback_ripper_no_per_title.md) — `rip_disc` shells `makemkvcon mkv ... all` once; per-title invocations cause USB-BD drive autosuspend / SCSI NOT_READY failures between titles.
- [Ripper runs unprivileged — read fingerprints device-side, never mount](feedback_ripper_unprivileged_no_mount.md) — `gosu` PUID-drop clears effective caps, so `cap_add: SYS_ADMIN` can't `mount`; compute CRC64 via `pydvdid_m.DvdId`/PyCdlib off the device. Don't add caps/privileged/AppArmor exceptions for the dropped service. CRC64 wire format for 1337server is plain 16-hex — strip pydvdid-m's `|` separator (a piped value misses every disc).
- [Backend test harness](project_backend_test_harness.md) — two tiers (fast fake-session router tests vs real-DB e2e under tests/e2e/); env/argon2/metadata gotchas; pre-existing test_dispatcher.py whole-suite collision.
- [Run pytest from repo root; no tests/__init__.py](pytest-invocation-and-no-tests-init.md) — bare `uv run pytest` (testpaths-driven); a file-path invocation OR a stray `__init__.py` in any `tests/` dir breaks `tests._fakes` collection across all 49 backend modules.
- [Backend coverage push](project_backend_coverage_push.md) — 70%→94% status; which modules still have gaps and the pattern to finish them; no CI gate yet.
- [Ripper disc-insert detection](project_ripper_insert_detection.md) — poll loop (no udev) + drive quirk (TRAY_OPEN ~2s flash, settles NOT_READY→DISC_OK) and the InsertDetector fix.
- [ISO-source ripping ships as virtual drives](project_iso_source_ripping.md) - "Rip from ISO" is built: each ISO rip is a temporary virtual Drive spawned/torn down through the existing ripper machinery and cleaned up by a 30s watchdog, not a cloned transcode-dispatcher task table; ARM_MANUAL_TRIGGER_ISO and the Import wizard are both gone; design/build doc at docs/developers/architecture/10-iso-source-ripping.md.
- [Pin GitHub Actions to commit SHAs](feedback_pin_actions_to_sha.md) — every `uses:` must be a 40-char SHA + `# vX.Y.Z`, never a tag/branch; dependabot keeps them bumped.
- [UI port: ui-neu on 8081; installer is canonical](feedback_ui_port_8081.md) - ui-neu (service/image `arm-ui`) on `https://localhost:8081` everywhere, Vue removed 2026-09-27, backend on 8080; never reconcile 8081 to 8080; the installer is the source of truth for deployment values.
